# セットアップガイド（Windows）

MP3・WAV・FLAC変換にはFFmpegとvgmstreamが必要です。一度準備すれば、以後はネット接続なしで使えます。アプリ内の自動ダウンロードを使わず、以下の手順で準備しても構いません。

## 1. FFmpegを導入する

スタートメニューから「ターミナル」または「PowerShell」を開き、次の1行を貼り付けて実行します。

```powershell
winget install --id Gyan.FFmpeg --exact --source winget
```

確認を求められたら表示された内容を読み、インストールを進めてください。コマンドを実行するのは利用者自身です。アプリがwingetを実行することはありません。

導入後はアプリを閉じて起動し直してください。開いたままのアプリでは、新しく追加されたPATHが反映されない場合があります。新しいターミナルで次を実行すると導入を確認できます。

```powershell
ffmpeg -version
```

wingetが使えない場合は[FFmpegのダウンロードページ](https://ffmpeg.org/download.html)からWindows用ビルドを入手し、ZIPをすべて展開します。アプリの「実行ファイルを選ぶ」で、展開先の`bin/ffmpeg.exe`を選択してください。

コマンドには[MicrosoftのWinGet登録にあるGyan.FFmpeg](https://github.com/microsoft/winget-pkgs/tree/master/manifests/g/Gyan/FFmpeg)を指定しています。

## 2. vgmstreamを準備する

1. [vgmstream公式ダウンロードページ](https://vgmstream.org/downloads/)を開きます。アプリの「音声読み取りツール」の「配布元を開く」からもアクセスできます。
2. Windows 64 bit用の`vgmstream-win64.zip`を取得し、「すべて展開」で解凍します。
3. アプリの「実行ファイルを選ぶ」で、展開先の`vgmstream-cli.exe`を選びます。DLLなど付属ファイルは移動・削除せず、展開時の構成を保ってください。

毎回場所を選ぶ必要はありません。選んだ実行ファイルの場所をアプリが記憶します。アプリ横の`tools/`に実行ファイルと付属DLLを置く方法でも検出できます。

## 3. アプリで確認する

「必要なツールを確認・準備」→「再確認」を押します。両方が「準備済み」になれば変換できます。検出できなければ、各ツールの「実行ファイルを選ぶ」で場所を指定してください。FFmpegの場所は新しいターミナルで`where.exe ffmpeg`を実行して調べられます。

## 自動ダウンロードを使う場合

各ツールの「自動ダウンロード」または「必要なツールをまとめて導入」を選びます。登録済みの配布ZIPを取得し、SHA-256の照合後に展開します。既に準備済みのツールはまとめて導入の対象から外れます。「中止」でダウンロードを中断できます。

失敗した場合は画面内に理由を表示します。再試行するか、上記の手動導入を使ってください。対応ZIPを事前に取得済みなら「ダウンロード済みZIPを選ぶ」も使えます。この取り込み方法はアプリに登録されたバージョンのZIP専用です。
